## Overview

Priya Deshmukh is elbow-deep in a stack of hand-inked florals when her phone buzzes against the
light table. Thistlebrook's production manager, calling for the third time today. Behind her,
pinned across two corkboards, hangs the same trailing-vine motif rendered two different ways: one
tiled in a plain, brick-straight grid, the edge of each square meeting the next like tile in a
bathroom; the other staggered, every other column dropped, the seams disappearing into the
pattern's own rhythm. Both are the same drawing. Neither is wrong.

The studio smells like spray-mount and burnt coffee. Somewhere under the pile is the licensing
term sheet her lawyer marked up last week, half the clauses still in red. Thistlebrook wants an
answer before their engraving room opens a job ticket Thursday morning — whichever repeat scheme
Priya signs off on gets burned onto the press cylinder, and cylinders are not something anyone
re-cuts on a whim.

She's spent six years building a client list on this vine pattern's reputation for looking
expensive without being unreasonable to print. This is the first time a mill this size has wanted
it for a whole yardage program instead of one throw-pillow run. Get the repeat scheme right and
it's the biggest single royalty check of her career. Get it wrong and either the seams show on
every sofa cushion made from her fabric, or Thistlebrook eats a setup cost that kills the reorder.

Priya opens the term sheet, pulls both corkboard photos into one browser tab, and starts typing.

## Background

Priya Deshmukh is an independent surface-pattern designer who licenses original repeat artwork to
fabric manufacturers for a running royalty per yard sold. She does not own or operate a press and
is not a party to Thistlebrook Textiles' own production economics, but the **repeat scheme** named
in the license is a term she controls and must choose before signing. Thistlebrook Textiles is a
mid-size home-décor fabric printer being asked to commit its printing setup — an engraved cylinder
that is expensive and slow to change once cut — to whichever repeat scheme the signed license
specifies.

Two repeat schemes are under negotiation for Priya's vine motif, each a fully alternative way of
tiling the same artwork across a bolt of fabric:

**The Straight Set** would tile the motif in a uniform grid: every repeat unit placed identically,
with no offset between adjacent columns. Under this scheme, every printed unit must run exactly as
drawn — a mirrored or rotated unit would create a visible break in the grid's straight lines (SEE
APPENDIX A).

**The Half-Drop** would offset every other column by half the motif's repeat height, the standard
technique surface-pattern designers use to break up a straight grid's visible seams. Because
alternating columns are already offset from one another, Thistlebrook's plate room confirms that
each column can independently run mirrored or as-drawn from the same single engraving with no
visible edge mismatch — a flexibility The Straight Set's zero-offset grid cannot offer (SEE
APPENDIX A). The Half-Drop's offset lattice also does not repeat with a single column's width: the
offset pattern itself (dropped column, un-dropped column, dropped column, …) only returns to its
starting arrangement every *second* column, so the smallest rectangular block that tiles the whole
fabric by pure straight-line translation alone — the scheme's *true* repeating tile — is twice as
wide as a single visual column, and contains more of the vine motif's distinct floral elements
before the tile genuinely closes (SEE APPENDIX A).

Both schemes must fit within Thistlebrook's actual printable fabric width on the rotary-screen
press it plans to run the job on (SEE APPENDIX B). Cutting a new engraved cylinder — one per repeat
scheme, one time, before any yardage prints — is Thistlebrook's dominant one-time setup cost, and
the two schemes do not cost the same to engrave, because the Half-Drop's offset lattice requires
tighter cross-column registration during engraving than the Straight Set's uniform grid (SEE
APPENDIX C). Once engraved, a cylinder is only rated for a fixed length of fabric before it wears
past tolerance and Thistlebrook has to re-cut it — that rated print run, combined with the real
fabric width, sets the total yardage either scheme can produce from a single setup (SEE APPENDIX
B).

Thistlebrook also wants the option to release a small "featured" capsule from whichever scheme
wins — a limited run recoloring a chosen subset of the vine motif's distinct floral elements in a
contrast thread, sold as a premium companion piece. How many distinct subsets of that size are even
possible depends on how many floral elements sit inside one *true* repeating tile — which, per
Appendix A, differs between the two schemes (SEE APPENDIX A).

Every dollar and yard figure Priya and Thistlebrook use to compare the two schemes is sourced in
**APPENDIX E**, or stated as an explicit modeling assumption in **APPENDIX D** where no public
figure exists. The vocabulary and "how to…" skills this case will ask of you are listed in
**APPENDIX G** — that is where Challenge 1 sends you. Curious about the real history and craft
behind repeat-pattern textile printing? SEE APPENDIX F for further reading.

B.) License the vine pattern as The Half-Drop — a half-drop repeat

**Why The Half-Drop's true tile is twice as wide, and holds double the floral elements.** A
half-drop offsets every other column by exactly half the repeat height. The offset *pattern itself*
(dropped, un-dropped, dropped, un-dropped, …) only returns to its starting arrangement every second
column, so the smallest rectangular block that tiles the whole fabric by pure straight-line
translation alone — the scheme's true repeating tile — is twice as *wide* as a single visual
column, and therefore contains twice as many of the motif's floral elements before the pattern
genuinely closes [S5].

**A note on symmetry, for context (not load-bearing).** The number of ways *any* 2-dimensional
repeating pattern's own rotational and reflective symmetry can combine with a translational grid is
not unlimited — it is a proven, closed classification: every possible periodic 2-D pattern's
symmetry falls into exactly **17 "wallpaper groups"** [S4], first proven in 1891. This license's
own configuration count (Challenge 3 D1) is far smaller than 17 — it is not attempting to exhaust
the mathematical space, only the specific choices this negotiation covers.

## Balance argument (facilitator only — never shipped to students)

**The trap, stated up front.** D2 alone makes The Half-Drop look like the easy winner: its true
repeating tile holds double the floral elements, so its featured-capsule subset count (C(12,2) =
**66**) beats The Straight Set's (C(6,2) = **15**) by better than 4-to-1. A Hero who stops at D2
will confidently recommend Option B on exactly that basis. **This is the wrong basis for the
case's own primary metric, and finding out why is the case.**

**Argument for A (The Straight Set).** Because both schemes share the same engraved cylinder
circumference (set by the motif's 27-inch repeat height, identical for both schemes) and the same
sourced screen life (30,000 meters, Appendix B), the two schemes produce the **same total printed
yardage** from one engraving — 32,808 yards. The only thing that differs is setup cost: The
Straight Set's simpler, uniform-grid engraving costs $650.00 against The Half-Drop's assumed
$750.00 (Appendix D, MA2). On the case's actual primary metric — yards per dollar of setup cost —
The Straight Set wins by construction whenever its engraving is cheaper, which it is here.

**Argument for B (The Half-Drop).** The primary metric measures raw yardage efficiency, not
commercial value. The Half-Drop's independent per-column mirror choice makes **8** licensable
printable configurations available from one engraving against The Straight Set's **4** (D1), and
its larger true tile supports **66** distinct featured-capsule variants against **15** (D2) — more
than four times the capsule assortment, and twice the base configuration count, from a setup that
costs only 15% more. If Thistlebrook can sell multiple colorways and capsule variants from the
*same* engraving without re-tooling, The Half-Drop converts a modest cost premium into
substantially more monetizable product variety per dollar of setup — a form of value the primary
metric does not capture at all.

**A finding worth naming directly.** D3's guarantee thresholds (5 repeat units for The Straight
Set, 9 for The Half-Drop) are both utterly dwarfed by the 131,232 repeat units either scheme
actually prints in a real run (D4a). **Neither scheme could honestly support a "no two repeats
identical" marketing claim** — with only 4 or 8 possible configurations cycling across a six-figure
print run, every configuration repeats tens of thousands of times. This is true regardless of which
option wins the primary metric, and it directly undercuts one plausible use Thistlebrook might have
had for The Half-Drop's larger configuration count.

**Margin.** `margin_pct` = **13.3**. `margin_basis`: compare each scheme's primary metric — total
printed yards producible from one engraving (32,808.4 yards, identical for both schemes under the
sourced/assumed figures), divided by that scheme's one-time engraving setup cost (Appendix C).
Computed: Option A = 32,808.4 ÷ $650.00 = **50.47 yards/$**. Option B = 32,808.4 ÷ $750.00 =
**43.74 yards/$**. The Straight Set wins by **13.3%** — genuinely close, and entirely dependent on
Appendix D MA2's stated engraving-cost premium, disclosed there as the case's single most
load-bearing dial.
