Overview

Priya Deshmukh is elbow-deep in a stack of hand-inked florals when her phone buzzes against the light table. Thistlebrook's production manager, calling for the third time today. Behind her, pinned across two corkboards, hangs the same trailing-vine motif rendered two different ways: one tiled in a plain, brick-straight grid, the edge of each square meeting the next like tile in a bathroom; the other staggered, every other column dropped, the seams disappearing into the pattern's own rhythm. Both are the same drawing. Neither is wrong.

The studio smells like spray-mount and burnt coffee. Somewhere under the pile is the licensing term sheet her lawyer marked up last week, half the clauses still in red. Thistlebrook wants an answer before their engraving room opens a job ticket Thursday morning — whichever repeat scheme Priya signs off on gets burned onto the press cylinder, and cylinders are not something anyone re-cuts on a whim.

She's spent years building a client list on this vine pattern's reputation for looking expensive without being unreasonable to print. This is the first time a mill this size has wanted it for a whole yardage program instead of one throw-pillow run. Get the repeat scheme right and it's the biggest single royalty check of her career. Get it wrong and either the seams show on every sofa cushion made from her fabric, or Thistlebrook eats a setup cost that kills the reorder.

Priya opens the term sheet, pulls both corkboard photos into one browser tab, and starts typing.

Background

Priya Deshmukh is an independent surface-pattern designer who licenses original repeat artwork to fabric manufacturers for a running royalty per yard sold. She does not own or operate a press and is not a party to Thistlebrook Textiles' own production economics, but the repeat scheme named in the license is a term she controls and must choose before signing. Thistlebrook Textiles is a mid-size home-décor fabric printer being asked to commit its printing setup — an engraved cylinder that is expensive and slow to change once cut — to whichever repeat scheme the signed license specifies.

Two repeat schemes are under negotiation for Priya's vine motif, each a fully alternative way of tiling the same artwork across a bolt of fabric:

The Straight Set would tile the motif in a uniform grid: every repeat unit placed identically, with no offset between adjacent columns. Under this scheme, every printed unit must run exactly as drawn — a mirrored or rotated unit would create a visible break in the grid's straight lines (see Appendix A).

The Half-Drop would offset every other column by half the motif's repeat height, the standard technique surface-pattern designers use to break up a straight grid's visible seams. Because alternating columns are already offset from one another, Thistlebrook's plate room confirms that each column can independently run mirrored or as-drawn from the same single engraving with no visible edge mismatch — a flexibility The Straight Set's zero-offset grid cannot offer (see Appendix A). The Half-Drop's offset lattice also does not repeat with a single column's width: the offset pattern itself (dropped column, un-dropped column, dropped column, …) only returns to its starting arrangement every second column, so the smallest rectangular block that tiles the whole fabric by pure straight-line translation alone — the scheme's true repeating tile — is twice as wide as a single visual column, and contains more of the vine motif's distinct floral elements before the tile genuinely closes (see Appendix A).

Both schemes must fit within Thistlebrook's actual printable fabric width on the rotary-screen press it plans to run the job on (see Appendix B). Cutting a new engraved cylinder — one per repeat scheme, one time, before any yardage prints — is Thistlebrook's dominant one-time setup cost, and the two schemes do not cost the same to engrave, because the Half-Drop's offset lattice requires tighter cross-column registration during engraving than the Straight Set's uniform grid (see Appendix C). Once engraved, a cylinder is only rated for a fixed length of fabric before it wears past tolerance and Thistlebrook has to re-cut it — that rated print run, combined with the real fabric width, sets the total yardage either scheme can produce from a single setup (see Appendix B).

Thistlebrook also wants the option to release a small "featured" capsule from whichever scheme wins — a limited run recoloring a chosen subset of the vine motif's distinct floral elements in a contrast thread, sold as a premium companion piece. How many distinct subsets of that size are even possible depends on how many floral elements sit inside one true repeating tile — which, per Appendix A, differs between the two schemes (see Appendix A).

Every dollar and yard figure Priya and Thistlebrook use to compare the two schemes is sourced in Appendix E, or stated as an explicit modeling assumption in Appendix D where no public figure exists. The vocabulary and "how to…" skills this case will ask of you are listed in Appendix F — that is where Challenge 1 sends you.

Why The Half-Drop's true tile is twice as wide, and holds double the floral elements. A half-drop offsets every other column by exactly half the repeat height. The offset pattern itself (dropped, un-dropped, dropped, un-dropped, …) only returns to its starting arrangement every second column, so the smallest rectangular block that tiles the whole fabric by pure straight-line translation alone — the scheme's true repeating tile — is twice as wide as a single visual column, and therefore contains twice as many of the motif's floral elements before the pattern genuinely closes [S5].

A note on symmetry, for context (not load-bearing). The number of ways any 2-dimensional repeating pattern's own rotational and reflective symmetry can combine with a translational grid is not unlimited — it is a proven, closed classification: every possible periodic 2-D pattern's symmetry falls into exactly 17 "wallpaper groups" [S4], first proven in 1891. This license's own configuration count (Challenge 3 D1) is far smaller than that — it is not attempting to exhaust the mathematical space, only the specific choices this negotiation covers.

    Working Notebook

    This is a calculator, not an answer key. Type your own numbers first — then hit Check to see if your arithmetic matches. It won't tell you which option to choose; that part is still yours.

    Step 1 — D1: printable configurations (Fundamental Counting Principle)

    4 licensed colorways. The Straight Set has no independent per-column choice (a mirrored unit would break the grid); The Half-Drop lets each column run mirrored or as-drawn, independently, from the same engraving. Multiply each scheme's independent stages.

    Step 2 — D2: featured-capsule subsets (binomial coefficient)

    A featured capsule recolors 2 floral elements chosen from one true, fully-repeating tile. The Straight Set's true tile holds 6 floral elements; The Half-Drop's holds 12 (Appendix A). Compute C(n, 2) for each.

    Step 3 — D3: guaranteed-repeat collision (Pigeonhole Principle)

    Use your Step 1 configuration counts as the number of pigeonholes. How many repeat units (pigeons) does a run need before two are guaranteed to show the identical configuration? Then compute the actual repeat units in a real production run: repeats across Thistlebrook's real 54″ fabric width × repeats along one engraving's full rated print run (same for both schemes — identical cylinder circumference and screen life).

    Compare your two guarantee thresholds to that actual run size. Could Thistlebrook honestly market a featured capsule as "no two repeats identical"? Write your reasoning in your pitch — the calculator won't answer that part for you.

    Step 4 — D4: setup-dollar synthesis (the case's primary metric)

    Convert one engraving's full rated print run to yards. Divide by each scheme's one-time engraving setup cost (Appendix C) to get yards producible per dollar of setup cost — this case's primary metric. Then, separately, divide your Step 2 capsule count by the same setup cost for a second, secondary dollar-efficiency figure.

    Reveal the Twist

    Everyone in this room has now computed D1 and D2. Someone read the featured-capsule subset count out loud — and The Half-Drop's number is visibly, dramatically larger than The Straight Set's. On design flexibility alone, The Half-Drop looks like a landslide winner.
